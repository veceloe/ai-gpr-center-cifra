# Бизнес-эффект

Метод расчёта задан заказчиком: считать в сэкономленных трудочасах и сокращении критического пути операции; переводить в деньги через среднюю рыночную ставку по данным HeadHunter, поскольку реальные ставки сотрудников не раскрываются.

## Как есть

| Параметр | Значение | Источник |
|---|---|---|
| Ручной мониторинг информационного поля | 3–4 ч/день на службу PR/GR | описание кейса |
| Носитель результата | Excel-реестр, 46 карточек, сквозная нумерация | реестр заказчика |
| Обновление реестра | периодически, вручную, с перепечатыванием | саммари созвона, разд. 3.2 |
| Общий дайджест | 1 раз в неделю (понедельник/пятница) | саммари созвона, разд. 3.4 |
| Проблемы формата | долго заполнять, неудобно читать, неудобно менять, не подходит руководителю | саммари созвона, разд. 10.2 |

## Как будет

Целевой ориентир заказчика: **утренний разбор суточной повестки занимает 10–15 минут** вместо 3–4 часов.

## Расчёт

Консервативный сценарий — экономия 2,5 ч из 3,5 ч в день на одного специалиста:

```
2,5 ч/день × 21 рабочий день   = 52,5 ч/мес на специалиста
52,5 ч × 12 мес                = 630 ч/год на специалиста
```

При двух профильных специалистах (PR + GR) в одной компании группы: **1 260 ч/год**.

Перевод в деньги — подставляется актуальная медиана HeadHunter по позициям «PR-менеджер» и «GR-специалист» в Москве на дату защиты:

```
Годовой эффект = 1 260 ч × (медианная месячная ЗП / 164 ч)
```

Формула, а не готовое число: подставить свежую медиану hh.ru при подготовке презентации и указать дату выгрузки. Цифра, взятая с потолка, на защите разрушает доверие ко всему расчёту.

Масштабирование: GS Group включает несколько компаний с собственными PR/GR-подразделениями («Триколор» назывался как кандидат на пилот). Эффект умножается на число подразделений без роста стоимости системы — меняется только профиль компании.

## Как правильно трактовать экономию

Заказчик отдельно оговорил: сэкономленные часы не означают сокращения фонда оплаты труда. Освободившееся время направляется на другие обязанности, развитие, обучение, более содержательную работу вместо чтения и заполнения таблиц. В презентации формулировать как **рост эффективности специалиста**, а не как сокращение затрат на персонал.

## Второй контур эффекта: риск немониторинга

Подсказан заказчиком отдельно и на защите работает сильнее часов, потому что переводит продукт из «удобства» в «управление риском».

Цена пропущенного регуляторного изменения: штрафы, внеплановые проверки, судебные разбирательства, репутационные потери, вплоть до уголовных дел. Конкретика из реестра заказчика:

- **ПП № 1937** — поэтапные требования совместимости реестрового ПО с доверенными ОС начиная с 01.09.2026. Пропуск срока = исключение из реестра российского ПО = потеря преимущества в закупках 44-ФЗ/223-ФЗ.
- **Законопроект CAS DRM (№ 1215252-8)** — обязательный переход на реестровые системы условного доступа с 01.01.2027, при исключении используемой системы из реестра даётся 6 месяцев на замену. Прямое влияние на ключевой продукт.
- **ФЗ № 295-ФЗ** — штрафы операторам цифровых платформ до 500 тыс. ₽.
- **Указ № 604 от 24.08.2026** — при непринятии мер по безопасности объектов критической инфраструктуры вводится временное управление имуществом владельца.

Упущенная выгода на другой стороне: гранты с софинансированием до 80% по поручениям ЦИПР-2026, региональные ставки УСН для ИТ, налоговые льготы за внедрение ИИ. Пропущенный срок подачи = недополученные деньги.

**Формулировка для защиты:** продукт экономит 630 часов в год на специалиста и одновременно закрывает риск, где цена одного пропуска превышает годовую стоимость всей системы.
