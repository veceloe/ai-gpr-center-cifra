## Тип D — внутренние файлы

GR-дайджесты (еженедельно), дайджесты ЭБР для АРПП, мониторинг законодательства ассоциаций — приходят файлами.
В MVP покрываются ручным добавлением материала (FR-041), автоматический разбор вложений вне скоупа.

## Отбор для MVP

Требование — 5 источников разных типов. Рекомендуемый набор, покрывающий все три категории кейса и обе сущности продукта:

1. `sozd.duma.gov.ru` — НПА, стадии, версии (обязателен: без него нет досье НПА)
2. `regulation.gov.ru` — проекты НПА на обсуждении
3. `t.me/government_rus` + `t.me/arppsoft` — Telegram
4. `telesputnik.ru` — отраслевое СМИ (RSS)
5. `vedomosti.ru` — деловое СМИ (RSS)

## Замечания к сбору

- Telegram: канал доступен как публичная веб-версия `t.me/s/<channel>`, что снимает потребность в API-ключах на этапе прототипа. Решение зафиксировано в ADR-0004.
- Ведомости и Коммерсантъ отдают часть материалов по подписке — рассчитывать нужно на заголовок и анонс, полный текст может быть недоступен. Это влияет на заземление саммари.
- Частота опроса задаётся одной общей настройкой сервиса сбора; индивидуальная частота на источник заказчиком признана избыточной для прототипа.
