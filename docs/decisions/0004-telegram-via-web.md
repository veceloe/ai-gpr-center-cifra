# ADR-0004. Telegram-каналы собираются через публичную веб-версию t.me/s/

**Дата:** 2026-09-02 · **Статус:** заменён ADR-0008 (03.09.2026 — риск авторизации Telethon снят драфтом news_parser)

## Контекст

Десять из четырнадцати источников заказчика — публичные Telegram-каналы. Штатный путь — Telethon с API-ключами (api_id/api_hash) и номером телефона: требует регистрации приложения, авторизации сессии и хранения учётных данных, что на хакатоне создаёт риск сорвать демо.

## Решение

На этапе прототипа читаем публичные каналы через веб-версию `https://t.me/s/<channel>`: HTML со списком последних постов, без ключей и авторизации. Слой сбора изолируется интерфейсом `SourceAdapter`, чтобы замена на Telethon была локальной.

## Альтернативы

- **Telethon / MTProto.** Отвергнуто для прототипа как источник риска и задержки; сохранено как путь развития — обязателен для закрытых каналов и глубокой истории.
- **Сторонние агрегаторы Telegram.** Отвергнуто: внешняя зависимость и ограничения по количеству запросов.

## Следствия

Доступны только публичные каналы и ограниченная глубина ленты. Для демо этого достаточно: все каналы заказчика публичны. Риск — изменение вёрстки t.me; парсер покрывается тестом на сохранённом снимке страницы.
