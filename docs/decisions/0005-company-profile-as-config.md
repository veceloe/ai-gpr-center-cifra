# ADR-0005. Профиль компании — конфигурация, а не захардкоженная логика

**Дата:** 2026-09-02 · **Статус:** принято

## Контекст

Ценность материала определяется его эффектом для конкретной компании. Формализованной системы правил «если А, то Б» у специалистов нет; решения строятся на опыте, и контекст меняется со временем. На созвоне обсуждалась возможность передавать описание компании в промпт, чтобы одна система оценивала материалы с точки зрения разных компаний. Заказчик рассматривает пилот в других компаниях группы, назывался «Триколор».

## Решение

Профиль компании — отдельный конфигурационный артефакт (`docs/company-profile.md` как человекочитаемый источник, `config/company_profile.yaml` как машинный): отрасль, продукты, налоговые режимы, аккредитации, зоны риска, зоны роста, конкуренты, явные признаки шума. Он подставляется в промпты релевантности и оценки. Смена профиля меняет оценку всей ленты без изменения кода.

## Альтернативы

- **Ключевые слова в коде.** Отвергнуто: не переносится на другую компанию, не отражает косвенную релевантность, ломается при смене контекста.
- **Дообучение модели под компанию.** Отвергнуто: нет данных и нет времени; неоправданно для задачи.

## Следствия

Демонстрируемая масштабируемость: переключение профиля на другую компанию группы в реальном времени — сильный аргумент на защите. Обратная сторона: качество оценки напрямую зависит от качества профиля, поэтому его состав требует подтверждения заказчиком (открытый вопрос OQ-06).
