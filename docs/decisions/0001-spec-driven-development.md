# ADR-0001. Работа по GitHub Spec Kit, спецификация как источник истины

**Дата:** 2026-09-02 · **Статус:** принято

## Контекст

Команда — AI Product Manager и два AI Engineer. Основной объём кода пишут агенты. Времени на хакатоне мало, цена расхождения между тем, что задумал PM, и тем, что сгенерировал агент, — сутки работы.

## Решение

Ведём проект по GitHub Spec Kit. Источник истины — `specs/001-ai-monitoring-center/spec.md`, код производен от него. Цикл: `/speckit-constitution` → `/speckit-specify` → `/speckit-clarify` → `/speckit-plan` → `/speckit-tasks` → `/speckit-analyze` → `/speckit-implement`. Изменение поведения начинается с правки спецификации.

## Альтернативы

- **Обычный PRD + свободная работа в Cursor.** Отвергнуто: PRD написан для человека, который достраивает недосказанное из контекста; агент достраивает иначе, и расхождение обнаруживается только на демо.
- **Сразу код без спецификации.** Отвергнуто: два инженера параллельно без общего контракта дают несовместимые куски.

## Следствия

Ревью спецификации выполняет агент с чистым контекстом, а не тот, что её писал. Требования трассируемы: FR-### → задача в `tasks.md` → проверка. Стоимость: примерно полдня на артефакты до кода.
