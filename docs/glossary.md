# Глоссарий

Один термин — одно значение. Агенты и участники обязаны использовать эти слова буквально.

| Термин | Значение | Чем НЕ является |
|---|---|---|
| **Материал** | Любая собранная единица контента до классификации | не «новость» и не «НПА», пока тип не определён |
| **Новость** | Одноразовый материал: прочитал → решил → закрыл | не имеет жизненного цикла и версий |
| **НПА** | Нормативно-правовой акт или его проект, отслеживаемый как долгоживущее досье | не карточка новости |
| **Досье НПА** | Сущность со стадиями, версиями, отзывами, слушаниями и историей оценок | не лента событий вокруг темы |
| **Стадия** | Положение НПА в жизненном цикле: анонс → проект → внесён → чтения → принят → вступил в силу | не «статус задачи пользователя» |
| **Событие** | Кластер публикаций об одном факте (результат дедупликации) | не элемент хронологии НПА |
| **Профиль компании** | Конфигурация в `docs/company-profile.md`, задающая, что релевантно | не карточка организации-субъекта новости |
| **Релевантность** | Наличие связи материала с профилем компании | не «интересность» и не тональность |
| **ИВ** | Индекс влияния НПА, 0–100, формула по К1–К6 | не приоритет, назначенный LLM |
| **ИА** | Индекс актуальности новости, 0–100, формула по Н1–Н4 | не ИВ |
| **Категория влияния** | Незначительное / Низкое / Среднее / Высокое / Критическое — производная от ИВ и флагов | не тематическая категория |
| **Тематическая категория** | Регуляторика / Репутация / Конкуренты / Тренды | не категория влияния |
| **Флаг эскалации** | Признак из закрытого списка, повышающий итоговую категорию на ступень | не ручная пометка «срочно» |
| **Заземление** | Привязка каждого утверждения саммари к фрагменту оригинала | не ссылка на источник |
| **Дайджест** | Подборка материалов, собранная под конкретного получателя | не вся лента |
| **Шум** | Материал без установленной связи с профилем компании | не «плохо написанный текст» |
| **Оценка (Assessment)** | Набор баллов по критериям + вычисленный индекс + автор (ai/human) + версия промпта | не одно число |
