# Quickstart

Как поднять систему и проверить, что она делает то, что обещано. Пишется до кода — это определение готовности, по которому инженеры поймут, что задача закрыта.

## Требования окружения

- Python 3.11+, Node 20+
- Ключ основного LLM-провайдера в `.env` (`LLM_API_KEY`, `LLM_PROVIDER`)
- Резервный провайдер настроен и проверен **до дня защиты**, а не в день защиты

## Запуск

```bash
cd backend && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
python -m src.cli init-db          # схема + сиды: источники, профиль компании, конфиг оценки
python -m src.cli seed-sources     # 5 источников из docs/sources.md
uvicorn src.api.main:app --reload  # http://localhost:8000
```

```bash
cd frontend && npm install && npm run dev   # http://localhost:5173
```

## Проверка качества

```bash
python -m src.cli evaluate --dataset evals/registry_46.jsonl
```

Выводит: базовую ставку, baseline большинства, recall и precision по классу «релевантно», accuracy рядом с базовой ставкой, полноту на «Высокое/Критическое», MAE по каждому критерию отдельно, доли отбраковки по обеим ступеням заземления.

**Порог готовности к защите:**

- recall по «релевантно» ≥0,80 при precision ≥0,70 (SC-005);
- результат превосходит baseline большинства (SC-013);
- **ноль** провалов критичного в «Низкое» (SC-006).

Последнее важнее всего: заказчик назвал его ключевым условием. Отчёт, в котором accuracy указана без базовой ставки, недействителен (SC-005a): такая цифра проходится классификатором «всё нерелевантно».

## Проверка производительности

```bash
python -m src.cli benchmark --items 20
```

Проверяет SC-003 (10–15 секунд на публикацию) и SC-004 (фильтры менее секунды). Замер выполняется с **выключенным кешем** — иначе цифра лжёт.

## Подготовка к демонстрации

1. Прогнать полный сбор заранее и прогреть кеш ответов модели — демо не должно зависеть от сети.
2. Проверить переключение на резервного провайдера: остановить основной, убедиться, что система продолжает работать.
3. Подготовить сценарий: лента за сутки → карточка с раскрытой оценкой → правка балла → досье НПА с хронологией → переключение профиля.
4. Держать наготове ответ на «чем вы лучше Brand Analytics»: досье НПА с динамикой влияния и оценка под конкретный профиль компании — ни того, ни другого у медиа-мониторинга нет.
