# Интеллектуальный центр PR/GR-мониторинга

Кейс ООО «Цифра» (GS Labs), ITMO AI Product Hack. Продукт заменяет 3–4 часа ежедневного ручного мониторинга информационного поля на 10–15 минут утреннего разбора.

**Состояние: артефакты до кода готовы. Код — драфт `news_parser/`, интегрируется по фазе 1.5 `tasks.md`.**

Проект ведётся по [GitHub Spec Kit](https://github.com/github/spec-kit): источник истины — спецификация, код производен от неё.

## Три решения, определяющие продукт

1. **Индекс считает код, не модель.** LLM выставляет баллы 0–3 по критериям методики заказчика с обоснованием на каждый балл; индекс, категорию и флаги эскалации вычисляет формула. Оценка объяснима, воспроизводима и измерима покритериально. — ADR-0003
2. **Новость и НПА — разные сущности.** Новость закрывается после прочтения, НПА живёт досье со стадиями, версиями и динамикой влияния. Это то, чего нет у медиа-мониторинга. — ADR-0002
3. **Профиль компании — конфигурация.** Смена профиля переоценивает всю ленту без единой правки кода, что открывает пилот в других компаниях группы. — ADR-0005
