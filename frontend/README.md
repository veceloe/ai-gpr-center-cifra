# frontend

Интерфейс по `specs/001-ai-monitoring-center/`. React 18 + TypeScript + Vite.

## Запуск

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173, /api проксируется на :8000
```

Backend должен быть запущен отдельно (`backend/README.md`).

## Сборка

```bash
npm run build        # кладёт результат в backend/static
npm run typecheck    # tsc --noEmit, без ошибок
```

После сборки приложение отдаётся самим backend по адресу `http://localhost:8000/` —
тем же процессом и портом, что API. Ни CORS, ни адреса API в конфигурации нет.

## Экраны

| Путь | Что делает |
|---|---|
| `/` | Лента: сортировка по влиянию, фильтры, поиск, раскрытие разбора оценки |
| `/acts`, `/acts/:id` | Досье НПА: стадии, хронология, динамика влияния |
| `/digests` | Сборка дайджеста под получателя и выгрузка |
| `/sources` | Источники: добавление, сбор, ошибки; ручное добавление материала |
| `/profile` | Профиль компании — конфигурация релевантности |

## Решения, которые видно в коде

**Раскрытие вниз, а не боковой панелью** (`components/ItemDetail.tsx`). Шесть
баллов складываются в индекс — по юзабилити-тесту IBM это случай вертикального
инлайн-раскрытия. Боковая панель уместна, когда деталь дополняет, а не
составляет итог.

**Балл — сегментированный контрол 0-3** (`components/ScoreBreakdown.tsx`), не
поле ввода: один клик, нет валидации, нет ошибок. Пересчёт индекса локальный,
подтверждение не спрашивается, отмена живёт в тосте восемь секунд.

**Правка не двигает ленту** (`pages/FeedPage.tsx`). Строка обновляется точечно:
перезагрузка списка пересортировала бы его по индексу, и карточка уехала бы
из-под курсора ровно во время работы с ней.

**Цвет только для двух верхних уровней серьёзности** (`styles/app.css`). Пять
цветов на сорока карточках дают светофор; сортировка по индексу уже выполнила
работу, интерфейс лишь не мешает. Нижние уровни приглушаются, а не прячутся.

**Четыре состояния стадии** (`pages/ActPage.tsx`), включая «неприменима».
Российские акты стадии пропускают: отзыв, возврат субъекту инициативы, принятие
без отдельного чтения. Линейная шкала без этого состояния вводит в заблуждение.

## Клавиатура в ленте

`j` / `↓` — следующий материал, `k` / `↑` — предыдущий, `Space` — раскрыть
разбор, `Esc` — свернуть, `?` — подсказка.
